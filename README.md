# Retitle

לוקליזציה של טריילרים לעברית.

- **כותרות על המסך:** הטקסט במקור נמחק, הרקע משוחזר מהפריימים השכנים באותו שוט, והעברית מוצבת באותו מקום, גודל, צבע, צל ואנימציה, בדיוק פריים.
- **דיאלוג:** תמלול ב-Whisper, ויצוא SRT בעברית (UTF-8) עם כללי תזמון: מינימום שנייה, 0.3 שנ' אחרי הדיבור, הצמדה לחיתוכים ו-2 פריימים בין כתוביות.

## התקנה (Windows)

1. מורידים את `Retitle-win64.zip` מהגרסה האחרונה בעמוד Releases.
2. מחלצים לתיקייה ומפעילים את `Retitle.exe`. נפתח חלון שחור (משאירים אותו פתוח) והאפליקציה נפתחת בדפדפן.

## שימוש

1. **בחר סרטון.** תיקיית עבודה נוצרת ליד הסרטון (`<שם>_retitle`).
2. **נתח כותרות.** לכל כותרת: תמונה, טקסט מקור, ותיבה לעברית. לבטל סימון לקרדיטים, לוגואים ושמות באנגלית.
3. מקלידים עברית, או **תרגם אוטומטית** (צריך מפתח API בהגדרות). אפשר לשנות גופן, משקל, גודל, צבע, יישור והזזה.
4. **בנה תצוגה מקדימה,** ואחרי תיקוני טקסט **עדכן עברית בלבד** (מהיר).
5. **תמלל,** מקלידים או מתרגמים אוטומטית, ואז **צור SRT.**
6. **ייצא סרטון.** בסוף מוצגת בדיקה של כל כותרת: פריים לפני הכניסה עד אחרי היציאה, מקור מול תוצאה.

בפעם הראשונה שמתמללים, Whisper מוריד מודל (כ-3GB ל-large-v3).

## מה לא אוטומטי

לוגו שם הסרט בעיצוב מיוחד: אפשר לשים במקומו תמונת PNG שקופה (`layer: {"type": "image", "path": ...}` ב-titles.json) והיא תקבל את אותה אנימציה כמו המקור.

## שורת פקודה

`python -m rt --help` - אותו מנוע, צעד אחר צעד.
