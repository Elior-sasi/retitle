# Retitle

לוקליזציה של טריילרים לעברית, בתוכנת Windows.

- **כותרות על המסך:** הטקסט במקור נמחק, הרקע משוחזר מפריימים שכנים באותו שוט, והעברית מוצבת באותו מקום, גודל, צבע, צל ואנימציה, בדיוק פריים.
- **דיאלוג:** תמלול ב-Whisper ויצוא SRT בעברית (UTF-8), עם כללי תזמון: מינימום שנייה, 0.3 שנ' אחרי הדיבור, הצמדה לחיתוכים ו-2 פריימים בין כתוביות.

## התקנה

1. מורידים את `Retitle-win64.zip` מהגרסה האחרונה בעמוד Releases.
2. מחלצים ומפעילים את `Retitle.exe`.

## המסך

- **למעלה:** פתח סרטון, נתח כותרות, תמלל דיאלוג, תרגם אוטומטית, בנה תצוגה, ייצא.
- **ימין:** רשימת הכותרות או הכתוביות.
- **מרכז:** נגן, עם מעבר בין מקור לתוצאה (T).
- **שמאל:** מאפייני הפריט הנבחר: עברית, גופן, משקל, גודל, צבע, יישור, הזזה ותזמון. כל שינוי מוצג מיד על הפריים.
- **למטה:** ציר זמן. גוררים קצוות של בלוק כדי לשנות זמנים. ההצמדה היא לחיתוכים ולמיקום הנגן.

קיצורים: רווח לניגון, חיצים לפריים, Shift+חיצים לשנייה, I/O לכניסה ויציאה, [ ] לפריט קודם/הבא, Ctrl+Z / Ctrl+Y לביטול ולביצוע שוב. הרשימה המלאה בכפתור "קיצורים".

בפעם הראשונה שמתמללים, Whisper מוריד מודל (כ-3GB ל-large-v3).

## לוגו שם הסרט

לוגו בעיצוב מיוחד: אפשר לשים במקומו PNG שקוף (`layer: {"type": "image", "path": ...}` ב-titles.json), והוא יקבל את אותה אנימציה כמו המקור.

## שורת פקודה

`python -m rt --help` - אותו מנוע, צעד אחר צעד.
